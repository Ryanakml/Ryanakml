## `⚙️` How I Build

```text
$ diagnose
  │  Reproduce → isolate → trace to origin, not the nearest symptom

$ architect
  │  Design the system before touching implementation

$ build
  │  Solo, end-to-end — every project above shipped without a team

$ ship
  │  Deployed, monitored, revenue-ready — not a demo
```
